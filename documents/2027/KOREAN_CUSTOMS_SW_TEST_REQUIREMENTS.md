# 통관 컴파일러 핵심 SW/Test 요구사항 — 한국어 실행 규격

> **<u>업무 로직을 이후 단계로 미루지 말 것.</u>** [AUTO_ENGINE_ALGORITHMS_AND_WORK_PROCESS.md](AUTO_ENGINE_ALGORITHMS_AND_WORK_PROCESS.md)는 실제 구매처·3PL·합배송·통관/신고주체·DDP·운송사 후보를 알고리즘으로 평가하는 핵심 설계다. 해당 문서의 입력·후보 생성·총원가·제약검사·실행/실패복구 및 ENG-01~20 테스트가 이 문서의 추상적 표현보다 우선한다. **현재 제품 기능 구현 완료를 뜻하지 않음.**

**<u>이 문서는 [제품 헌장](PRODUCT_VISION_COMPILER_AND_MD.md)의 역직구 컴파일러가 실제 고객에게 정확한 상품·수입 가능 여부·총도착가격·DDP/배송 계획을 돌려주기 위한 필수 검증 계약이다.</u>** 문서에 적힌 법률/관세율은 최신 공인 규정을 조사해 승인받아야 한다. 미확인 수치는 UNKNOWN이며 자동승인 불가. 단순 URL 제목 추출은 성공 기준에 포함하지 않는다.

## 4. Golden Test Vector — 필수, 가상 세율로 대체 금지

**국가·제품군·통관 경로별** 공인 세율표와 실제 관세사/운송사 검토를 통한 입력/기대결과를 별도 버전으로 기록한다.

필수 컬럼: `caseId, country, regime, effectiveFrom, effectiveTo, exactSKU, variant, manufacturerOrigin, hs6Candidate, verifiedNationalTariffCode, commodityComposition, salePrice, currency, declaredValue, freight, insurance, importerOfRecord, incoterm, additionalDutyRule, dutyBase, dutyAmount, importTaxBase, importTaxAmount, clearanceFee, carrierDdpEligible, officialSourceUrl, sourceReviewedAt, reviewer, expectedStatus`.

테스트는 **① 분류 ② 수입 적격성 ③ 법정 관세/세금 ④ 운송사 통관비 ⑤ DDP/DDP 불가 분기 ⑥ 최종 고객 비용 ⑦ 실제 청구와 차액**까지 분리하고, 승인된 Golden Case는 해당 범위 내에서 금액/상태 100% 일치가 기준이다. 검증되지 않은 케이스는 승인 상태가 아니라 `DRAFT`이며 실제 고객용 결제를 열지 않는다. 최소 샘플 수는 출시할 국가×상품군×수입경로 범위를 먼저 확정해 실제 브로커와 결정한다.

공식 근거 시작점: https://www.cbp.gov/ , https://hts.usitc.gov/ , https://www.customs.go.jp/english/tariff/ , https://online.customs.gov.cn/ .

## 5. MD·컴파일러 통합 테스트

- 같은 상품을 URL 직접 입력할 때와 MD에서 고를 때 **같은 HS/규제/세금/배송 엔진 결과**가 나와야 한다.
- 미국/중국의 동일 SKU 현지 판매가격 증거가 없으면 '현지보다 저렴' 배지·절감액 표시 불가.
- 상품명만 파싱하고 제조국/재질이 빠지면 고객 화면에서 '부분 분석'과 누락 이유가 나타난다.
- 미확인 DDP 노선에는 '관세 포함' 표시가 없어야 한다.
- 로그인 고객의 첫 화면은 활성 주문이면 실제 트래킹 우선, 비로그인/주문 없는 회원은 MD/URL 우선.
- 실제 운임 견적 없는 합배송 절감액, 실제 스캔 없는 배송 완료, 근거 없는 ETA 표시 금지.

**현재 기준:** 이 파일은 상세 요구/시험 명세이지만 실제 규정 승인·코드 구현·E2E 실행 기록이 아니다.
