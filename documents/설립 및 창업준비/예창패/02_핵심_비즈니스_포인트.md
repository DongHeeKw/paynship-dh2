## 1. 왜 지금인가 (Why Now)

### 시장 타이밍

**K-콘텐츠의 글로벌 확산이 구매 수요를 폭발시켰지만, 한국 이커머스는 구조적으로 해외 소비자를 차단하고 있다.**

| 지표 | 수치 | 성장 |
|------|------|------|
| 역직구 수출액 (2025) | **3조 234억원** | 전년 대비 +16.4% |
| K-뷰티 수출 (2024) | **100억 달러** | 사상 최초 돌파 |
| 역직구 4년 CAGR | **18%** | — |
| K-뷰티 역직구 5년 성장 | **18배** | 781억→1.4조원 |
| 크로스보더 물류 시장 (2025) | **$49.5억** | → 2030 $69.1억 |

### 기술 타이밍

- LLM 비용 2023년 대비 **1/10 수준**으로 하락 (Gemini Flash: $0.10/1M tokens)
- 이전에는 비용상 불가능했던 "AI가 쇼핑을 대행하는 모델"이 상업적으로 실현 가능해진 최초의 시점

## 2. 결제 장벽 상세 분석 (Problem 핵심 근거)

### 한국 이커머스의 "3중 잠금"

**왜 해외 소비자가 쿠팡에서 물건을 못 살까?**

```
잠금 1: 본인인증 (CI/DI)
  → 한국 통신사 가입 휴대폰 번호 필수
  → 외국인등록증(ARC) 없으면 인증 자체 불가
  → 네이버페이, 카카오페이, 토스페이 전부 이 인증 필요

잠금 2: 국내 전용 PG사
  → 이니시스, KCP, 토스페이먼츠 등 한국 PG
  → 한국 발급 카드(삼성/신한/국민)에 최적화
  → Visa/MC라도 해외 발급이면 결제 실패 빈번

잠금 3: 간편결제 생태계 폐쇄
  → 네이버페이: 한국 계좌 연동 필수
  → 카카오페이: 한국 휴대폰 인증 + 한국 계좌
  → 쿠팡페이: 한국 카드 전용
  → PayPal, Apple Pay 미지원 (대부분)
```

### 플랫폼별 해외 소비자 접근성

| 플랫폼 | 월 방문 | 해외카드 | 회원가입 | 국제배송 | 실질 접근성 |
|--------|--------|---------|---------|---------|-----------|
| **쿠팡** | 1.5억+ | △ 일부 | ❌ 한국번호 | ❌ | **거의 불가** |
| **네이버 쇼핑** | 8,000만+ | ❌ | ❌ CI/DI | ❌ | **완전 불가** |
| **무신사** | 3,000만+ | ❌ | ❌ 한국번호 | ❌ | **완전 불가** |
| **올리브영** | 2,000만+ | ❌ | ❌ 한국번호 | ❌ (글로벌몰 별도) | **완전 불가** |
| **G마켓 글로벌** | 300만+ | ✅ PayPal | ✅ 이메일 | ✅ | ✅ (상품 한정) |

→ 한국 이커머스 상위 4개 플랫폼(쿠팡·네이버·무신사·올리브영)에서 해외 소비자의 직접 구매가 **사실상 불가능**

**심사위원 메시지**: "글로벌 사이트(G마켓 글로벌, 11번가 글로벌)는 전체 상품의 5~10%만 취급. 90%의 한국 상품은 해외 소비자에게 잠겨 있다."

## 3. End-to-End 경험의 차별화 (Solution 핵심 근거)

### "대행업자를 없앤다"는 것의 구체적 의미

기존 구매대행에서 **사람이 하는 일 6가지**를 AI가 모두 자동화한다:

| # | 기존: 사람(대행업자)이 하는 일 | PayNShip: AI가 하는 일 |
|---|------------------------------|----------------------|
| 1 | 고객 요청을 이해 (카톡/메일) | **Semantic Router** — 자연어 의도 분류 (20ms) |
| 2 | 한국 사이트에서 상품 검색 | **Web Scraper** — 쿠팡·네이버 등 자동 검색 |
| 3 | 상품 정보를 읽고 고객에게 번역·설명 | **LLM 자동 해석** — 상품명, 옵션, 성분, 리뷰 구조화 |
| 4 | 옵션(사이즈/색상) 확인 후 고객과 재소통 | **Slot Filling** — 대화형으로 옵션 자동 수집 |
| 5 | 견적 수동 계산 (엑셀/계산기) | **Calculator Engine** — 배송비+관세+VAT 실시간 자동 |
| 6 | 한국 카드로 대신 결제 + 배송 수배 | **Shopify Checkout** — 사용자가 직접 글로벌 카드 결제 |

**핵심**: 기존에는 대행업자에게 돈을 먼저 보내고 믿어야 했다. PayNShip에서는 **사용자가 직접 Shopify에서 결제**하므로 신뢰 문제가 구조적으로 제거된다.

### 시간 비교

| 단계 | 기존 구매대행 | PayNShip |
|------|------------|----------|
| 상품 검색 | 30분~수시간 (사용자가 직접) | **< 3초** (AI 자동) |
| 견적 확인 | 24~72시간 (대행업자 응답 대기) | **< 5초** (실시간) |
| 결제 | 선불 입금 후 대기 | **즉시** (글로벌 카드) |
| 배송 추적 | 카톡으로 문의 | **자동** (웹훅 기반) |
| **전체** | **24~72시간** | **< 5분** |

**PayNShip의 구조적 차별화**:
1. **AI 자동화** → 스케일러블, 한계비용 거의 0
2. **관세 포함 실시간 견적** → 가격 투명성
3. **사용자 직접 결제** → 신뢰 문제 제거
4. **< 5분 E2E** → 즉시성

## 5. 기술 차별화 포인트 (Deep Tech 강조)

### Point 1: 3-Tier 스크래핑 캐스케이드 — "기술이 곧 마진"

경쟁사가 모든 페이지에 LLM을 호출하면 건당 $0.01~0.03. PayNShip은 무료 추출(Tier 1/2)을 우선 시도하여 **70%를 무료로 처리**.

```
월 10만건 처리 시:
  경쟁사: $1,000~3,000/월
  PayNShip: ~$150/월
  → 비용 차이가 곧 마진 차이
```

### Point 2: Semantic Router — AI 비용 75% 절감

| 방식 | 속도 | 건당 비용 | 정확도 |
|------|------|----------|--------|
| LLM 전수 호출 | ~800ms | $0.003 | 95% |
| **Semantic Router + LLM 폴백** | **~20ms** | **$0.0008** | **93%+** |

### Point 3: 17개국 관세 엔진 — "이것만으로도 B2B SaaS 가능"

| 데이터 | 규모 |
|--------|------|
| 대상 국가 | 17개국 |
| HS Code 분류 | 100+ 품목 |
| FTA 협정 | 47개+ |
| VAT/GST | 국가별 차등 |
| 면세 기준 | 국가별 Threshold |

### Point 4: 420+ 자동화 테스트 — "아이디어가 아니라 실행력"

예비창업 단계에서 이 수준의 시스템을 보유한 것은 이례적.

## 7. 팀 시너지: "기술 × 운영" 조합

### 김도윤 (CTO) — "만드는 사람"

PayNShip의 **전체 시스템을 단독 설계·구현**한 기술 창업자. 기술 투자, PM, 사업기획을 모두 경험하여 "기술적으로 가능한 것"과 "사업적으로 의미 있는 것"의 교차점을 찾는 역량.

**이 팀에서의 역할**: 제품 설계, 기술 개발, AI 모델 최적화, 시스템 아키텍처

### 박요한 (COO) — "파는 사람"

**발란(BALAAN) 부사장** 출신으로, 명품 크로스보더 거래의 운영 전반(물류, 정품인증, CS, 셀러관리)을 경험한 리테일 전문가. 이랜드 그룹에서 대규모 리테일 운영을 다수 수행.

**이 팀에서의 역할**: GTM 실행, 물류 파트너십, 운영 프로세스, 사업 전략

### 왜 이 조합이 강력한가

구매대행 서비스의 두 가지 핵심 역량:
1. **기술**: 상품 수집, 가격 계산, 결제 자동화 → 김도윤
2. **운영**: 물류, 고객 관리, 마케팅, 파트너십 → 박요한

→ 둘 중 하나만 있으면 반쪽짜리. 이 팀은 **양쪽을 모두 커버**.
