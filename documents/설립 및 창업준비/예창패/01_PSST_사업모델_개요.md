# PayNShip 예비창업패키지 PSST 사업모델 개요

> **문서 목적**: 예비창업패키지 사업계획서(PSST) 작성을 위한 논리 구조 및 핵심 논거 정리
> **작성일**: 2026-03-04
> **버전**: v2.0 (피드백 반영: UX 흐름 강조, 결제 장벽 상세화, 시장 데이터 보강, 팀 구성 확정)

---

## Executive Summary

한국 역직구 시장은 2025년 **3조원**(관세청)을 돌파하며 연평균 18% 성장 중이나, 해외 소비자가 쿠팡·네이버·무신사에서 직접 구매하는 것은 사실상 불가능하다. 한국 휴대폰 본인인증(CI/DI), 국내 전용 PG사, 한국어 전용 UI라는 3중 장벽이 존재하기 때문이다.

PayNShip은 **AI 에이전트가 상품 페이지를 자동 번역·해석하고, 옵션 선택부터 결제·국제배송까지 전 과정을 중간 대행업자 없이 End-to-End로 처리**하는 서비스다. 사용자는 "BTS 앨범 사줘"라고 채팅하면 5분 안에 관세 포함 최종 가격을 확인하고 결제할 수 있다.

기술+리테일 운영 경험의 공동창업팀(김도윤: 기술/PM, 박요한: 발란 부사장/리테일 운영)이 이미 프로덕션 수준의 시스템(420+ 자동화 테스트)을 완성한 상태다.

## P — Problem (문제 인식)

### 1. 시장 배경: "K-콘텐츠는 글로벌인데, K-쇼핑은 잠겨 있다"

K-pop, K-beauty, K-food의 글로벌 수요가 폭발적으로 증가했지만, 해외 소비자가 한국 상품을 실제로 구매하는 경로는 극도로 제한적이다.

**시장 규모 (공식 통계)**:

| 지표 | 수치 | 출처 |
|------|------|------|
| 역직구 수출액 (2025) | **3조 234억원** (전년 대비 +16.4%) | 관세청 |
| 역직구 수출액 (2024) | **2조 5,976억원** | 관세청 |
| 최근 4년 연평균 성장률 | **18%** | 관세청 |
| K-뷰티 수출 (2024) | **100억 달러** 돌파 (사상 최초) | 산업부/관세청 |
| K-뷰티 역직구 (2024) | **1.4조원** (2019년 781억 대비 18배) | KITA |
| 역직구 건수 (2024.08 기준) | **6,117만건** | 관세청 |

**국가별 비중**: 미국(38%) > 중국(24%) > 일본(14%) > 동남아(나머지)

**카테고리별 비중**: 화장품(32%) > 의류/패션(21%) > 건강식품(14%) > 식품(11%) > 음반/비디오(6.4%)

### 2. 핵심 문제: 한국 이커머스의 3중 잠금

해외 소비자가 한국 쇼핑몰에서 직접 구매하려면 3가지 구조적 장벽에 부딪힌다.

#### 장벽 1: 결제 차단 — "카드가 있어도 못 산다"

한국 이커머스는 국내 PG사(이니시스, KCP, 토스페이먼츠 등) 기반의 독자적 결제 시스템을 사용한다. 이 시스템은 구조적으로 해외 소비자를 차단한다.

| 플랫폼 | 해외카드 결제 | 회원가입 | 실질 구매 가능성 |
|--------|-------------|---------|----------------|
| **쿠팡** | 일부 가능 (Visa/MC) | 한국 번호 본인인증 필요 | ❌ 로켓배송·로켓와우·쿠팡플레이 불가 |
| **네이버 쇼핑** | ❌ 네이버페이 한국 인증 필수 | CI/DI 본인인증 (한국 휴대폰) | ❌ 사실상 불가 |
| **무신사** | ❌ 국내 PG사 전용 | 한국 휴대폰 인증 | ❌ 불가 |
| **11번가** | 일부 가능 (글로벌 사이트) | 이메일 가입 가능 | △ 글로벌 전용 상품만 |
| **G마켓 글로벌** | PayPal/해외카드 | 이메일 가입 | △ 글로벌 셀러 한정, 국내 상품 대부분 미포함 |
| **올리브영** | ❌ | 한국 번호 필요 | ❌ 불가 (글로벌몰은 별도 운영, 상품 한정) |

**결제 차단의 기술적 원인**:
- **CI/DI 본인인증**: 한국 통신사 가입 휴대폰 번호로만 본인인증 가능. 외국인등록증(ARC) 소지자만 예외적으로 가능하나, 해외 거주자는 완전히 차단
- **국내 PG사 독점**: 이니시스, KCP 등 한국 PG사는 한국 발급 카드(삼성/신한/국민 등)에 최적화. Visa/MC라도 해외 발급 카드면 결제 실패 빈번
- **간편결제 잠금**: 네이버페이, 카카오페이, 토스페이 모두 한국 휴대폰 인증 + 한국 계좌 연동 필수

#### 장벽 2: 언어 — "상품이 뭔지 알 수 없다"

- 쿠팡, 네이버, 무신사 등 주요 쇼핑몰의 상품 페이지는 **100% 한국어**
- 상품명, 옵션(사이즈/색상), 배송 조건, 교환/환불 정책 모두 한국어
- 구글 번역으로 페이지를 번역해도 옵션 선택 드롭다운, 장바구니 UI 등은 번역 불가
- 상품 상세 이미지 내 텍스트(성분표, 사이즈표 등)는 기계 번역 자체가 불가능

#### 장벽 3: 물류 — "배송비가 얼마인지 모른다"

- 대부분 한국 쇼핑몰은 **국제배송 미지원** (국내 배송만 가능)
- 국제배송을 지원하는 경우에도 배송비 계산이 불투명
- **관세·VAT가 별도**: 소비자가 도착지 국가의 관세율, 면세 한도를 직접 파악해야 함
- 면세 기준이 국가마다 다름: 미국 $800, EU €150, 일본 ¥16,666, 호주 AUD1,000

### 3. 기존 해결 방식의 한계 — "대행업자에게 의존하는 10년 전 모델"

현재 해외 소비자의 한국 상품 구매 경로는 크게 4가지인데, 모두 본질적 한계가 있다.

| 기존 방식 | 대표 서비스 | 수수료 | 소요 시간 | 핵심 문제 |
|-----------|-----------|--------|----------|----------|
| **수동 구매대행** | 카페/SNS 개인 대행 | 10~20% (불투명) | 24~72시간 (소통) | 사기 리스크, 가격 불투명, 스케일 불가 |
| **구매대행 플랫폼** | KoreanBuddies, Harumio, KoreaToMe | 8~15% + 배송비 | 수시간~1일 | 수동 견적, 관세 미포함, 소통 병목 |
| **배송대행** | 몰테일, Korgou, PINKBOX | 배송비만 | 사용자가 직접 구매 | 결제 장벽 해결 안 됨, 한국어 필요 |
| **글로벌 마켓플레이스** | G마켓 글로벌, 11번가 글로벌 | 마켓 수수료 | 즉시 | 상품 한정 (전체의 5~10%), 가격 높음 |

**핵심 페인포인트 요약**: 해외 소비자는 (1) 한국 사이트에 가입조차 못하고, (2) 가입해도 결제가 안 되고, (3) 결제가 되어도 배송이 안 되며, (4) 대행업자를 쓰면 비용·시간이 과다하다.

## S — Solution (해결 방안 / 실현 가능성)

### 1. 핵심 가치: "대행업자 없이, AI가 직접 쇼핑 전 과정을 처리"

기존 구매대행은 **사람(대행업자)**이 병목이다. PayNShip은 이 사람을 **AI 에이전트**로 대체하여, 사용자가 자연어 대화만으로 상품 파악→결제→배송까지 원스톱으로 경험하게 한다.

### 2. End-to-End 사용자 경험 (기존과의 결정적 차이)

```
[기존: 수동 구매대행 — 5단계, 24~72시간]
사용자가 한국 사이트 탐색 (한국어)
  → 대행업자에게 링크 전달 + 옵션 설명 (소통 24h+)
  → 대행업자가 견적 산출 (수동, 관세 미포함)
  → 사용자가 입금 (선불, 환불 어려움)
  → 대행업자가 구매 + 국제배송 (추적 불투명)

[PayNShip: AI 자동화 — 3단계, < 5분]
사용자: "I want to buy this BTS album" (자연어 또는 URL 붙여넣기)
  → AI가 자동으로:
     ① 상품 페이지 스크래핑 + 자동 번역 (가격, 옵션, 사이즈, 성분 등)
     ② 옵션 선택 대화 ("Which version? Random or specific member?")
     ③ 실시간 총비용 계산 (상품가 + 국내배송 + 국제배송 + 관세 + VAT)
     ④ Shopify 결제 (글로벌 카드/PayPal) → 배송 추적
```

### 3. 구체적 UX 시나리오 (데모 시연용)

**시나리오 1: URL 직접 입력**
```
사용자: [쿠팡 URL 붙여넣기]
AI: "이 상품은 '이니스프리 그린티 세럼 80ml'이네요.
     - 가격: ₩23,000 (~$16.40)
     - 옵션: 80ml / 160ml
     어떤 사이즈로 하시겠어요?"
사용자: "80ml, 2개"
AI: "미국으로 배송 시 총 비용입니다:
     상품: $32.80
     국제배송: $12.00
     관세: $0 (미국 $800 면세 한도 이내)
     서비스 수수료: $4.48
     ───────────
     총계: $49.28
     결제하시겠어요?"
사용자: "Yes"
AI: [Shopify 결제 링크 생성 → 글로벌 카드/PayPal 결제]
```

**시나리오 2: 자연어 검색**
```
사용자: "I need Korean skincare for dry skin, budget under $30"
AI: [네이버 쇼핑 + 쿠팡 동시 검색]
    "3가지 추천 상품을 찾았어요:
     1. 라네즈 워터뱅크 크림 $24.50 ★4.8
     2. 이니스프리 그린티 세럼 $16.40 ★4.7
     3. 닥터지 레드 블레미쉬 클리어 크림 $18.90 ★4.6
     각 상품의 성분표와 리뷰를 번역해 드릴까요?"
```

**핵심 차별점 — "왜 대행업자가 필요 없는가"**:

| 기존 대행업자가 하는 일 | PayNShip AI가 자동으로 하는 일 |
|----------------------|---------------------------|
| 상품 페이지를 읽고 고객에게 설명 | 상품 페이지 자동 스크래핑 + 자연어 번역·요약 |
| 옵션·사이즈를 고객과 소통하며 확인 | Multi-turn 대화로 옵션 Slot Filling |
| 견적서를 수동 계산하여 전달 | 실시간 자동 계산 (배송비 + 관세 + VAT) |
| 한국 카드로 대신 결제 | Shopify 결제 (사용자가 직접 글로벌 카드로 결제) |
| 국제배송 수배 + 추적 | 물류 파트너 자동 연동 + 실시간 추적 |

### 4. 핵심 기술 스택

#### 4-1. AI Agent (LLM Orchestrator) — 자연어로 쇼핑하는 엔진
- **Semantic Router**: 패턴 매칭 기반 **20ms** 내 의도 분류 → LLM 호출 비용 75% 절감
- **10가지 Action Type**: search, show_product, parse_url, add_to_cart, calculate_shipping, checkout 등
- **Multi-turn Slot Filling**: 사이즈·색상·수량 등 옵션을 대화형으로 자연스럽게 수집
- **SSE 스트리밍**: 실시간 처리 상태를 사용자에게 표시 ("상품 정보를 가져오는 중...")
- **상품 페이지 자동 해석**: 한국어 상품명, 옵션, 가격, 리뷰를 AI가 읽고 영어로 구조화

#### 4-2. 3-Tier Scraping Cascade — 비용 70% 절감
| Tier | 방식 | 속도 | 비용 | 커버리지 |
|------|------|------|------|---------|
| **Tier 1** | JSON-LD / Schema.org | ~50ms | **무료** | 구조화된 사이트 |
| **Tier 2** | CSS Selectors (사이트별) | ~200ms | **무료** | 쿠팡, 네이버 등 |
| **Tier 3** | LLM 파싱 (Gemini Vision) | ~800ms | $0.005/건 | 모든 사이트 |

→ Tier 1~2에서 **70%+** 해결, LLM은 최후 수단으로만 사용

#### 4-3. 17개국 관세·배송비 계산 엔진
- **17개국 배송비**: 국가별 무게·부피 기반 요금 매트릭스 (US, JP, CN, SG, AU, GB, DE, FR, CA 등)
- **HS Code 기반 관세**: 100+ 품목, 47개+ FTA 협정 우대세율 반영
- **국가별 VAT/GST**: 미국 Sales Tax, EU VAT(17~27%), AU GST(10%), 일본 소비세(10%)
- **면세 기준 자동 판별**: 미국 $800, EU €150, 일본 ¥16,666 등

#### 4-4. Shopify Headless Commerce — 글로벌 결제 해결
- 한국 PG사를 우회하여 **Shopify 결제**(Visa, MC, PayPal, Apple Pay) 사용
- Draft Order + CustomLineItems로 PayNShip 가격을 그대로 반영
- 사용자가 직접 결제 → 대행업자에게 선불하는 불안감 제거

### 5. 구현 완성도 (MVP가 아닌 Production-Ready)

| 모듈 | 상태 | 테스트 수 |
|------|------|----------|
| AI Chat Agent | **Production** | 69+ |
| Web Scraper | **Production** | 208+ |

→ **예비창업 단계에서 이미 프로덕션 시스템을 보유** — 실현 가능성의 가장 강력한 증거

### 6. 기술적 해자 (Technical Moat)

1. **3-Tier Cascade**: 경쟁사 대비 스크래핑 비용 70%+ 절감
2. **Semantic Router**: LLM API 비용 75% 절감 → 영업이익률 직결
3. **17개국 관세 엔진**: HS Code + FTA 반영, 구축에 6개월+ 소요되는 진입장벽
4. **Data Confidence Scoring**: 7단계 신뢰도로 데이터 정확성 투명화

## S — Scale-up (성장 전략)

### 1. 시장 규모 (TAM → SAM → SOM)

| 구분 | 정의 | 규모 | 근거 |
|------|------|------|------|
| **TAM** | 한국 역직구 전체 시장 | **3조원** (2025) | 관세청 통계 |
| **SAM** | 온라인 구매대행/배송대행 시장 (영어권 + 동아시아) | **~8,000억원** | 역직구 중 비플랫폼 거래 비중 추정 |
| **SOM** | 1차 타겟 (미국·일본 K-콘텐츠 팬, AI 구매대행 전환 가능) | **~200억원** | 보수적 추정 |

### 2. 수익 모델
