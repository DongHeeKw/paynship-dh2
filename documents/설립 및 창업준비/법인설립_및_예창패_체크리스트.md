# PayNShip 법인설립 & 예창패 준비 체크리스트

> **작성일**: 2026-03-02
> **지분구조**: 51:49 또는 60:40 (Doyun 우위)
> **아이템**: AI 기반 한국 상품 해외 구매대행 (PayNShip)

---

## Executive Summary

1. **예창패 먼저, 법인은 선정 후** — 예비창업패키지는 사업자등록 전 상태여야 신청 가능. 2026년 공고가 이미 나왔거나 임박한 시점(과거 패턴: 2월 중순~3월 초 접수)이므로 K-Startup 즉시 확인 필요.
2. **주주간계약서가 법인설립보다 선행** — 지분, 베스팅, 탈퇴조건을 법인 전에 합의해야 정관에 반영 가능.
3. **51:49 vs 60:40 선택은 투자 유치 계획에 따라 결정** — 51:49는 상호 견제 구조(특별결의 거부권), 60:40은 대표의 실질적 지배력 확보.

## Phase 0: 지금 즉시 (예창패 신청 준비)

### 예창패 공고 확인 & 신청
- [ ] [K-Startup](https://www.k-startup.go.kr/) 접속 → 2026 예비창업패키지 공고 확인
- [ ] [창업진흥원 사업공고](https://www.kised.or.kr/menu.es?mid=a10302000000) 확인
- [ ] K-Startup 회원가입 & 알림 설정
- [ ] 주관기관 선택 (아이템 적합성, 접근성, 멘토링 역량 기준)

### 사업계획서 작성 (PSST 구조)

**1. Problem (문제인식)**
- [ ] 해외 소비자의 한국 상품 구매 페인포인트 정의 (결제 장벽, 언어, 배송 불투명성)
- [ ] TAM/SAM/SOM 시장규모 산출 (K-Commerce 해외 직구 시장 데이터)
- [ ] PEST 분석 (한류 트렌드, 크로스보더 이커머스 성장률 등)

**2. Solution (실현 가능성)**
- [ ] AI 에이전트 기반 구매대행 솔루션 구체화 (URL 파싱 → 자동 견적 → 결제 → 배송)
- [ ] 기술 차별점 정리: LLM 기반 의도 분류, 3-Tier 스크래핑, 자동 관세/배송 계산
- [ ] 시제품(MVP) 현황 기술 — 이미 작동하는 프로토타입 보유 (강점)
- [ ] 사업화 자금 집행 계획 (시제품 고도화, 서버, 마케팅 등)

**3. Scale-up (성장전략)**
- [ ] 경쟁사 분석 (Buyee, KoreanBuddy, Gmarket Global 등) — 차별점 매트릭스
- [ ] 수익모델 구체화 (수수료 구조, 마진율)
- [ ] 고객 획득 전략 (타겟 국가별 마케팅 채널)
- [ ] 단계별 확장 계획 (국가, 카테고리, 기능)

**4. Team (팀 구성)**
- [ ] 각 창업자 역할/역량 정리 (기술, 비즈니스)
- [ ] 채용 계획 (사업화 자금 활용)

### 예창패 제출 서류
- [ ] 사업계획서 (K-Startup 양식)
- [ ] 대표자 신분증 사본
- [ ] 주민등록등본 (지역 배정용)
- [ ] (해당 시) 기술 관련 증빙 (특허, 논문, 수상 등)
- [ ] (해당 시) 고객 검증 자료 (설문, LOI, 사전 예약 등)

### 예창패 유의사항
- [ ] 신청 시점 기준 **사업자등록 없어야 함** (법인 설립 X)
- [ ] 접수 기간 약 2~3주 → 마감 2~3일 전 제출 권장
- [ ] 달성 가능한 목표 설정 (미달성 시 향후 지원사업 신청에 영향)

## Phase 1: 주주간 합의 (법인설립 전 필수)

### 지분구조 결정
- [ ] **51:49 vs 60:40 최종 결정**

| 비교 항목 | 51:49 | 60:40 |
|-----------|-------|-------|
| 보통결의 (과반수) | 51% 단독 통과 가능 | 60% 단독 통과 가능 |
| 특별결의 (2/3) | 49% 동의 필수 (거부권 존재) | 40%가 반대해도 통과 불가능 → 사실상 동일하게 40% 동의 필요 |
| 투자 유치 시 희석 | 여유 좁음 | 상대적 여유 |
| 동업자 관계 | 대등에 가까운 파트너십 | 대표 주도권 명확 |
| 과점주주 간주세 | 51% → 과점주주 해당 (취득세 주의) | 60% → 과점주주 해당 |

- [ ] 주당 금액 결정 (보통 5,000원 or 100원)
- [ ] 총 발행주식수 결정
- [ ] 자본금 결정 (최소 100만원~, 통상 1,000만~5,000만원)

### 주주간계약서 (SHA) 작성
> 법인설립 전에 체결해야 정관에 반영 가능

**필수 조항 체크리스트:**
- [ ] **지분비율** — 정확한 주식수, 비율, 납입금 명시
- [ ] **업무 분담** — 각자 담당 영역 (CEO/CTO 등), 의무 근무시간
- [ ] **의사결정 구조**
  - [ ] 일반 경영사항: 대표이사 단독 결정 범위
  - [ ] 중요사항 (투자유치, 대출, 자산처분 등): 전원 동의 또는 이사회 결의
  - [ ] 교착상태(Deadlock) 해소 절차
- [ ] **베스팅(Vesting)** — 4년 베스팅 + 1년 클리프 (일반적)
  - [ ] 중도 이탈 시 미확정 지분 처리 방법
- [ ] **지분양도 제한(Lock-up)** — 최소 2년 양도 금지
- [ ] **우선매수권(ROFR)** — 매각 시 기존 주주 우선 매수
- [ ] **동반매도청구권(Drag-along)** / **동반매도참여권(Tag-along)**
- [ ] **경업금지** — 재직 중 + 퇴사 후 1~2년 동종업계 금지
- [ ] **비밀유지(NDA)** — 사업 정보, 기술 정보
- [ ] **탈퇴/제명 조건** — 사유, 지분 정산 방법, 정산 가격 산정 기준
- [ ] **지적재산권(IP) 귀속** — 업무상 창작물은 회사 귀속
- [ ] **위약금/손해배상** — 위반 시 구체적 제재 (금액 or 지분 환수)
- [ ] **분쟁해결** — 중재/소송 관할

**주의**: 상법에 반하는 조항은 무효 → 전문가 검토 권장 (비용 50~200만원)

## Phase 2: 법인설립 (예창패 선정 후)

### 사전 준비
- [ ] 상호(법인명) 결정 → 동일 관할 내 중복 확인 (등기소 or 인터넷등기소)
- [ ] 사업목적 결정 (한국표준산업분류표 참고, 향후 확장 고려하여 넓게)
- [ ] 본점 소재지 확정 (임대차계약서 or 주소지)
- [ ] 정관 작성

### 정관 핵심 포함사항
- [ ] 상호, 사업목적, 본점 소재지
- [ ] 발행 예정 주식 총수 (발행주식의 4배 이상 권장 → 증자 여유)
- [ ] 1주의 금액
- [ ] 주식 양도 제한 조항 (이사회 승인 필요 → 원치 않는 주주 유입 방지)
- [ ] 이사/감사 수, 선임 방법, 임기
- [ ] 주주총회 소집 절차, 의결 정족수
- [ ] 배당 관련 규정
- [ ] (선택) 종류주식 발행 근거 조항 (향후 투자 대비)
- [ ] 공고 방법

### 법인설립 등기 절차
- [ ] **정관 작성 및 공증** (자본금 10억 미만은 발기인 기명날인으로 공증 갈음 가능)
- [ ] **주식 발행사항 결정** (발기인 총회 or 이사회)
- [ ] **자본금 납입** → 은행 잔고증명 발급
- [ ] **설립등기 신청** (관할 등기소 or [온라인법인설립시스템](https://www.startbiz.go.kr/))
  - [ ] 법인설립등기신청서
  - [ ] 정관
  - [ ] 발기인총회의사록
  - [ ] 이사/감사 취임승낙서
  - [ ] 주식인수증
  - [ ] 잔고증명서
  - [ ] 인감신고서 (법인인감)
  - [ ] 대표이사 주민등록등본
  - [ ] 임원 인감증명서
- [ ] **사업자등록** (관할 세무서 or 홈택스)
  - [ ] 법인등기부등본
  - [ ] 정관 사본
  - [ ] 주주명부
  - [ ] 임대차계약서 (사업장)
  - [ ] 대표자 신분증
- [ ] **법인 통장 개설** (은행)
- [ ] **4대 보험 가입 신고**

### 법인설립 비용 예상
| 항목 | 비용 (대략) |
|------|------------|
| 등록면허세 + 교육세 | 자본금의 0.48% (과밀억제권역 3배) |
| 등기수수료 | 약 2~3만원 |
| 법무사 수수료 (위임 시) | 30~50만원 |
| 주주간계약서 법률 검토 | 50~200만원 |
| 법인인감 제작 | 1~3만원 |
| **합계 (자본금 제외)** | **약 100~300만원** |

## Phase 3: 추가 정부 지원사업 검토

### 예비창업패키지 (최우선)
| 항목 | 내용 |
|------|------|
| 지원금 | 평균 5,000만원, 최대 1억원 |
| 대상 | 사업자등록 미보유 예비창업자 |
| 접수 | K-Startup 온라인 (2월 중순~3월 초 예상) |
| 평가 | 서류 → 발표 (PSST 기준) |
| 협약기간 | 약 8개월 |

### 함께 검토할 지원사업
- [ ] **초기창업패키지** — 창업 3년 이내, 최대 1억원 (이미 2026 공고 발표됨)
- [ ] **창업도약패키지** — 3~7년 차 기업, 최대 3억원
- [ ] **TIPS (기술창업 투자)** — 엔젤투자+정부매칭, 최대 5억원
- [ ] **지역별 창업지원** — 각 지자체 창업센터 프로그램
- [ ] **K-Startup 그랜드챌린지** — 외국인 or 글로벌 타겟 스타트업
- [ ] **중소벤처기업부 R&D** — 기술개발 지원

### 지원사업 공통 주의사항
- [ ] **중복 수혜 제한** 확인 (같은 부처 내 중복 불가 등)
- [ ] 사업계획서 간 일관성 유지
- [ ] 사업비 집행 규정 숙지 (부정수급 방지)

## Phase 4: 법인 운영 초기 셋업

### 세무/회계
- [ ] 세무사/회계사 선임 (월 10~20만원)
- [ ] 부가세 신고 주기 확인 (분기별)
- [ ] 법인세 신고 일정 확인 (3월)
- [ ] 원천세 신고 (급여 지급 시 매월)
- [ ] 인건비 4대보험 처리

### 지적재산권
- [ ] 상표등록 출원 (PayNShip 브랜드) — 특허청 키프리스 선행조사
- [ ] (해당 시) 특허/실용신안 출원 검토 (AI 스크래핑 기술 등)
- [ ] 도메인 확보

### 사업 인프라
- [ ] 사업용 계좌 분리 (개인 혼용 금지)
- [ ] 사업용 카드 발급
- [ ] 사업용 이메일/도메인 셋업
- [ ] (해당 시) 사무실/공유오피스 확보

## 의사결정 필요 사항

> 아래 항목들은 Doyun이 공동창업자와 직접 합의해야 할 사안입니다.

| # | 항목 | 선택지 | 권장 |
|---|------|--------|------|
| 1 | 지분비율 | 51:49 / 60:40 | 투자유치 계획 있으면 60:40 |
| 2 | 자본금 | 1,000만 / 3,000만 / 5,000만 | 3,000만원 (과밀억제권역 세금 고려) |

| 5 | Lock-up 기간 | 2년 / 3년 | 2년 |

## 타임라인 요약

```
[지금] ─── Phase 0: 예창패 신청 ───────────────────────
  │  K-Startup 공고 확인 & 사업계획서 작성
  │  주관기관 선택 & 접수
  │
[접수 후 1~2개월] ─── 서류/발표 평가 ──────────────────
  │
  │  ← 이 기간에 Phase 1 진행 (주주간 합의)
  │
[선정 발표] ─── Phase 2: 법인설립 ─────────────────────
  │  협약 체결 전 사업자등록
  │  법인설립 등기 → 사업자등록
  │
[협약 체결] ─── Phase 3-4: 사업 본격 시작 ─────────────
  │  사업비 집행 시작
  │  추가 지원사업 탐색
  │  세무/IP/인프라 셋업
```
