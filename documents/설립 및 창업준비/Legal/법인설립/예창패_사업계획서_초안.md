## 1. Problem (문제인식) — 30점

### 1-1. 창업 아이템 배경

**글로벌 한류 소비 시장의 구조적 문제**

한류(K-Culture)의 글로벌 확산으로 한국 상품에 대한 해외 수요가 급증하고 있지만, 실제 구매 과정에는 높은 장벽이 존재한다.

**핵심 페인포인트 (해외 소비자 관점):**

| 장벽 | 구체적 문제 | 영향 |
|------|-----------|------|
| 언어 | 쿠팡, 네이버쇼핑 등 한국어 전용 → 상품 옵션, 배송 정보 이해 불가 | 구매 포기 |
| 결제 | 한국 결제 시스템(이니시스, KG 등) → 해외 카드 결제 거부 빈번 | 결제 실패 |
| 배송 | 국제 배송비 불투명, 관세/VAT 사전 확인 불가 | 예상치 못한 추가 비용 |
| 정보 비대칭 | 상품 크기/무게/성분 정보 부족 → 관세 분류(HS Code) 자체를 모름 | 통관 지연/반송 |

**시장 데이터:**
- 글로벌 크로스보더 이커머스 시장: 2025년 약 $7.9조 → 2030년 $13.4조 예상 (CAGR 11.2%)
- 한국 상품 해외 직구 시장: 2024년 기준 약 [__]조원
- K-뷰티 글로벌 시장: 2023년 $14.4B → 2030년 $30.9B 전망
- K-푸드, K-팝 굿즈, K-패션 등 카테고리별 성장세 지속

> **출처 확보 필요**: 통계청 해외직접판매액, KOTRA 보고서, Statista 등에서 정량 데이터 보강

### 1-2. 창업 아이템 개요

**PayNShip = AI Shopping Agent for Korean Products**

사용자가 한국 쇼핑몰 URL을 채팅으로 보내면:
1. AI가 상품 정보를 자동 추출 (가격, 옵션, 이미지, 크기/무게)
2. 국가별 배송비 + 관세 + VAT를 실시간 계산하여 총 비용 제시
3. 장바구니에 담고, 안전한 결제 링크를 생성
4. 주문 확정 → 한국 내 구매 → 국제 배송 → 추적번호 제공

**기존 구매대행과의 차이:**
- 기존: 사람이 카카오톡/이메일로 수동 견적 → 24~48시간 소요
- PayNShip: AI가 실시간으로 30초 내 견적 완료 → 즉시 결제 가능

## 2. Solution (실현 가능성) — 30점

### 2-1. 기술 개발 현황 (MVP)

**이미 작동하는 프로토타입을 보유하고 있습니다.**

| 기능 | 구현 상태 | 기술 |
|------|----------|------|
| AI 챗 에이전트 | ✅ 완료 | LLM 기반 의도분류 + SSE 실시간 스트리밍 |
| 상품 정보 스크래핑 | ✅ 완료 | 3-Tier 추출 (JSON-LD → CSS → LLM), 534+ 테스트 통과 |
| 배송비 자동 계산 | ✅ 완료 | 17개국 지원, HS Code 기반 관세/VAT 포함 |
| 장바구니 & 견적 | ✅ 완료 | 세션 기반, 24시간 유효 견적서 생성 |
| 결제 연동 | ✅ 완료 | Shopify 결제 링크 자동 생성 |
| 주문/배송 추적 | ⚠️ 부분 | DB 구조 완료, E2E 테스트 진행 중 |

**핵심 기술 차별점:**

1. **3-Tier 스크래핑 캐스케이드**
   - Tier 1: JSON-LD 구조화 데이터 추출 (~50ms, 무료)
   - Tier 2: CSS 선택자 기반 파싱 (~200ms, 무료)
   - Tier 3: LLM 기반 HTML 분석 (~800ms, 건당 $0.005)
   - 비용 효율: 전체 요청의 약 70%가 Tier 1~2에서 처리 → 운영비 최소화

2. **AI 의도 분류 (Semantic Router)**
   - 패턴 매칭(20ms) → LLM 폴백(800ms) 이중 구조
   - "이거 장바구니에 담아줘", "3번째 상품 배송비 얼마야?" 같은 자연어 처리

3. **자동 관세 계산 엔진**
   - HS Code 자동 분류 (LLM + UNI-PASS API 연동)
   - 47개 FTA 협정 반영 → 특혜관세율 자동 적용
   - 17개국별 VAT/GST 계산
