## CPO vs CMO — 역할 비교

| 기준 | CPO (Chief Product Officer) | CMO (Chief Marketing Officer) |
|------|---------------------------|------------------------------|
| **핵심 책임** | 제품 전략, 우선순위, 로드맵 | 마케팅 전략, 브랜드, 고객 획득 |
| **일상 업무** | 사용자 리서치, 기능 기획, UX 방향 | 광고 집행, 콘텐츠, SNS, SEO |
| **의사결정** | "무엇을 만들 것인가" | "어떻게 팔 것인가" |
| **PayNShip에서** | AI 에이전트 UX, 스크래핑 결과 품질, 가격 정책 | Reddit/TikTok 마케팅, 인플루언서, CAC 관리 |
| **CTO와 관계** | 긴밀 (제품 방향 ↔ 기술 구현) | 독립적 (마케팅은 기술과 별개) |

**판단 포인트**: 박요한님이 "제품을 어떻게 설계할지"에 더 관여할지, "제품을 어떻게 팔지"에 더 집중할지.

- 초기 스타트업에서 CEO+CTO인 도윤이 제품 방향도 주도한다면 → **CMO**가 역할 충돌 적음
- 박요한님이 고객 관점에서 제품 우선순위를 적극적으로 결정한다면 → **CPO**가 적합

> **혼합 옵션**: COO + CMO로 하되, 제품 관련 의사결정은 "공동 협의"로 SHA에 명시하는 방법도 있음

## 🔀 대안 시나리오: 개인사업자 선창업 → 법인 Flipping

> **상황**: 박요한님이 법인 공동창업 대신 개인사업자로 먼저 사업을 시작하고,
> 추후 투자유치 또는 규모 확장 시 법인으로 전환(Flipping)하는 구조.

### 시나리오 개요

```
[Phase 1 — 지금]
  김도윤 → 개인사업자 or 1인 법인 설립 (원주, 세액감면)
  박요한 → 개인사업자 설립 (서울 또는 원주)
  두 사업자 간 5:5 수익배분 계약서 체결

[Phase 2 — 트리거 발생 시]
  투자유치 / 규모 확장 / 대형 파트너십 요구 →
  법인 설립 후 개인사업 자산/계약 법인에 Flipping
  SHA + 정관 체결 → 주주 구조 확정
```

### Phase 1 필요 서류 (개인사업자 구조)

| 서류 | 설명 | 비고 |
|------|------|------|
| **공동사업 약정서** | 두 개인사업자 간 수익 5:5 배분, 업무분담, 의사결정 방식 | 법적 구속력 있음 |
| **이탈방지 조항** | 약정 위반(무단 이탈, 경업) 시 위약금 / 손해배상 | 최소 2~3년 명시 |
| **IP 귀속 조항** | 공동 개발물의 귀속 및 법인 전환 시 이전 방식 | 라이선스 vs 양도 |
| **법인 전환 의무 조항** | 트리거(투자 / 매출 기준) 달성 시 법인 설립 및 Flipping 의무화 | 6개월 이내 이행 등 |
| **비밀유지 계약 (NDA)** | 공동 사업 정보 보호, 퇴사 후 24~36개월 | 독립 문서 or 약정서 포함 |

### Phase 2 — Flipping 시 필요 서류

| 서류 | 내용 | 주의 |
|------|------|------|
| **법인 설립 서류** | 정관, SHA, 발기인총회 의사록 (기존 초안 활용) | 지분비율 재확인 |
| **사업 양수도 계약서** | 개인사업자 자산(도메인, 코드, 계약, 고객 DB) → 법인 이전 | 양도가액 결정 필요 |
| **현물출자 동의서** | 현금 대신 자산으로 출자 시 (법원 검사인 필요) | 절차 복잡 → 현금 + 라이선스 권장 |
| **기존 계약 당사자 변경 동의** | 외주/파트너 계약을 법인 명의로 이전 | 계약 상대방 동의 필요 |
| **부가세 폐업신고** | 개인사업자 → 법인 전환 시 폐업 처리 | 폐업 후 잔여 재고/채권 정리 |
| **사업자등록 (법인)** | 홈택스 법인 사업자등록 | 법인설립등기 후 가능 |

### 개인사업자 구조 장단점

| 항목 | 개인사업자 선창업 | 법인 즉시 설립 |
|------|-----------------|--------------|
| **세금** | 소득세 6~45% (누진) | 법인세 9~24% (누진) → 초기 유리 |
| **세액감면** | 청년 100% 동일 가능 | 청년 100% 동일 |
| **예창패 신청** | ✅ 가능 (개인사업자 등록 전 신청) | ✅ 가능 |
| **계약/신뢰** | 대기업/투자자와 계약 약함 | 법인이 신뢰도 높음 |
| **지분 보호** | 약정서 의존 (법적 보호 약함) | SHA + 등기로 강력 보호 |
| **투자유치** | 어려움 (법인 필수) | 즉시 가능 |
| **설립 비용/절차** | 거의 없음 (무료) | 48,000원 + 인건비 등 |
| **리스크** | 을 이탈 시 법적 구제 어려움 | SHA 위약금 등 강력 보호 |

### ⚠️ 핵심 리스크 — 개인사업자 구조

**박요한님 이탈 방지 측면에서 법인이 훨씬 강력합니다.**
- 개인사업자 간 약정서는 법적으로 집행 가능하나, SHA보다 구조가 단순해 분쟁 시 불리
- 공동 작업물(코드, 고객 DB) 귀속이 불명확해 이탈 시 분쟁 가능
- **권장**: 투자 계획이 있다면 법인 즉시 설립 > 개인사업자 후 Flipping

### 개인사업자 약정서 주요 조항 (법인 Flipping 전 사용 시)

```

제2조 (수익 배분)
  순수익의 50% : 50%로 배분 (매월 정산)

  박요한: 운영·마케팅 총괄

제4조 (이탈방지)
  계약 후 [24]개월 이내 무단 이탈 시 위약금 금 [____]원
  경업금지: 이탈 후 [24]개월

제5조 (법인 전환 의무)

### 경영권 보호 해결책 (택1 또는 조합)

#### 방안 1: 창업자 복수의결권 (차등의결권) — **강력 권장**

2023년 상법 개정으로 **비상장 주식회사도 복수의결권 주식 발행 가능**.

```
정관 추가 조항 예시:
제○조 (종류주식 — 복수의결권)
① 창업자주식(갑·김도윤 보유분)은 1주당 3의결권을 부여한다.
② 복수의결권 주식은 다음 경우 소멸한다:
   - 갑이 대표이사직을 자의로 사임하는 경우
   - 갑이 주식을 제3자에게 양도하는 경우
   - 회사 IPO 시 (IPO 완료일로부터 5년 후 일몰)
```

**효과**: 갑이 액셀 투자 후 30% 지분만 남아도 3배수 의결권으로 과반 유지

|------------|----------|--------------|-----------|
| 갑 47.4% | 47.4 | ×3 = 142.2 | **53.4%** ✅ |
| 을 45.6% | 45.6 | ×1 = 45.6 | 17.1% |
| 액셀 7.0% | 7.0 | ×1 = 7.0 | 2.6% |

#### 방안 2: SHA에 창업자 지분 하한선 조항 추가

**한계**: 투자 라운드가 많아지면 결국 하한선에 걸릴 수 있음.

#### 방안 3: SAFE 또는 전환사채 구조 협상

초기 액셀러레이터 투자를 지분이 아닌 **SAFE(Simple Agreement for Future Equity)**로 받아, 지분 확정을 시리즈A 시점으로 미루는 전략.

```

**장점**: 지금 당장 경영권 걱정 없이 액셀 지원 수혜 가능.
