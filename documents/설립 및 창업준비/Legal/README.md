## 보강 필요 사항

### 예창패 사업계획서
- [ ] TAM/SAM/SOM 정량 데이터 (통계청, KOTRA, Statista)
- [ ] 공동창업자 역량/경력 기술
- [ ] 고객 검증 자료 (설문조사, 커뮨니티 반응, LOI)
- [ ] K-Startup 공식 양식에 맞춰 재작성
- [ ] 발표자료(PPT) 별도 제작

### 법적 문서
- [ ] 주주간계약서 법률 전문가 검토 (50~200만원)
- [ ] 상법 위반 조항 여부 확인
- [ ] 정관 등기소 적합성 확인

## 주의사항

1. **이 문서들은 법률 자문을 대체하지 않습니다.** 특히 주주간계약서와 정관은 반드시 변호사 또는 법무사 검토를 받으세요.
2. **예창패 신청 시점에 사업자등록이 없어야 합니다.** 법인설립은 반드시 선정 후.
3. **SHA → 정관 순서**. 주주간 합의가 선행되어야 정관에 올바르게 반영됩니다.
