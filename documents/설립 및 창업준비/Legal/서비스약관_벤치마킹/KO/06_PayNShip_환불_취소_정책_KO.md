## 요약

환불/취소는 **주문 단계별로 가능 범위가 달라지며**, 단계가 진행될수록 환불 가능 금액이 줄어듭니다. 구매대행 특성상 한국 소매점에서 구매가 완료된 이후에는 소매점의 반품 정책에 종속됩니다.

## 1. 주문 단계별 취소/환불 정책

### 1단계: 결제 전
| 항목 | 정책 |
|------|------|
| 장바구니 삭제 | 자유롭게 가능 |
| 견적 취소 | 자유롭게 가능 |
| 수수료 | 없음 |

### 2단계: 결제 후 ~ 구매 전
| 항목 | 정책 |
|------|------|
| 취소 가능 여부 | **가능** |
| 환불 금액 | 결제 금액 - 취소 처리 수수료 |
| 취소 처리 수수료 | **$5** |
| 환불 소요 기간 | 영업일 5~10일 |

### 3단계: 구매 후 ~ 창고 입고 전
| 항목 | 정책 |
|------|------|
| 취소 가능 여부 | **소매점 정책에 따름** |
| 조건 | 소매점이 취소/반품을 수락하는 경우에만 가능 |
| 공제 항목 | 취소 처리 수수료 ($5) + 서비스 수수료 (이미 발생분) + 거래 수수료 |
| 국내 배송비 | 이미 발송된 경우 환불 불가 |
| 소요 기간 | 소매점 처리 기간 + 영업일 5~10일 |

### 4단계: 창고 입고 후 ~ 국제배송 전
| 항목 | 정책 |
|------|------|
| 취소/반품 가능 여부 | **제한적** |
| 조건 | 소매점 반품 정책에 따름 + 입고 후 48시간 이내 요청 |
| 공제 항목 | 취소 처리 수수료 ($10) + 서비스 수수료 + 거래 수수료 + 국내 배송비(실비) + 반품 배송비(실비) |
| 소매점 거부 시 | 환불 불가 — 국제 배송 진행 또는 폐기(비용 고객 부담) |

### 5단계: 국제배송 후
| 항목 | 정책 |
|------|------|
| 취소/환불 | **불가** |
| 수령 거부 시 | 반송비 전액 고객 부담 |
| 관세 미납 반송 | 반송비 + 재배송비 고객 부담 |

## 3. 환불 방법

### 3.1 환불 수단
환불은 **원래 결제 수단**으로 처리됩니다.
- 신용카드: 카드사 정책에 따라 5~10 영업일
- PayPal: 3~5 영업일
- 기타: 결제사 정책에 따름

### 3.2 환불 통화
- 환불은 결제 시점의 통화로 처리
- 환율 변동으로 인한 차액은 보상하지 않음

---

## 4. 반품/교환이 불가능한 경우

다음의 경우 반품 및 교환이 불가합니다:

1. **개인 판매자 구매** (번개장터, 중고 거래 등) — 결제 완료 후 교환/반품 불가
2. **주문 제작 상품** — 커스텀 메이드, 각인 상품 등
3. **개봉/사용한 상품** — 내용물 확인 목적의 개봉 제외
4. **시간 경과로 가치 감소** — 재판매 어려운 수준
5. **포장 훼손** — 복제 가능한 상품의 포장이 훼손된 경우
6. **고객 과실 분실/파손** — 고객의 책임으로 상품 가치가 크게 감소한 경우
7. **단순 변심** — 원칙적으로 구매대행 완료 후 단순 변심 환불 불가

## 5. 상품 하자 시 처리

### 5.1 소매점 귀책 하자
소매점에서 잘못된 상품이 배송되었거나 제조 결함이 있는 경우:

1. 창고 입고 후 **48시간 이내** 고객센터 연락
2. 사진/영상 증거 제출
3. PayNShip이 소매점과 교환/반품 협의 대행
4. 소매점이 수락 시: 교환 또는 환불 처리 (국내 반품 배송비는 소매점 정책에 따름)
5. 소매점이 거부 시: PayNShip 면책 (소매점의 결정)

### 5.2 배송 중 파손
1. 수령 즉시 (또는 **48시간 이내**) 파손 사진과 함께 신고
2. PayNShip이 택배사 클레임 절차 지원
3. 보상은 택배사 보험 약관에 따름

### 5.3 PayNShip 귀책
PayNShip 창고 내에서의 분실/파손은 당사가 전액 보상합니다.

## 6. 분쟁 해결 절차

### 1단계: 고객센터 접수
- AI 채팅 또는 이메일로 문의
- 주문번호, 문제 상세, 증거 자료 첨부

### 2단계: 내부 검토 (영업일 3일 이내)
- 주문 이력, 소매점 정책, 택배사 정책 확인
- 고객에게 결과 및 가능한 해결방안 안내

### 3단계: 합의
- 양측 합의 시 환불/재배송/크레딧 등으로 처리

### 4단계: 추가 이의
- 합의가 안 될 경우 이용약관 제12조 (분쟁 해결)에 따름
- 대한민국 법률 적용, 한국 법원 관할

## 7. 특수 상황

### 7.1 소매점 품절/발송 불가
- 소매점에서 품절 또는 발송 불가 통보 시 전액 환불 (수수료 미공제)

### 7.2 환율 변동
- 결제 후 환율이 크게 변동하여 구매가가 달라진 경우:
  - 추가 비용 발생: 고객에게 추가 결제 요청 (고객이 거부 시 취소 가능, 취소 수수료 없음)
  - 비용 감소: 차액 환불

### 7.3 배송 지연
- 택배사 사유의 배송 지연은 환불 사유가 아님
- 30일 이상 배송 추적 불가 시 분실 처리 절차 개시
