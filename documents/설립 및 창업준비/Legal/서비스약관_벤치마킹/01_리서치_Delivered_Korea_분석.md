# Delivered Korea 서비스 약관/정책 리서치 분석

> **조사일**: 2026-03-08
> **대상**: https://www.delivered.co.kr
> **목적**: PayNShip 서비스 약관, 개인정보처리방침, 금지품목, 서비스 규칙 수립을 위한 벤치마킹

---

## Executive Summary

Delivered Korea는 부산 소재 한국 구매대행/배송대행 서비스로, "We Buy & Ship"(구매대행)과 "You Buy, We Ship"(배송대행) 두 가지 핵심 서비스를 운영한다. 약관은 영문 기반이며 Notion 페이지로 관리된다. PayNShip이 참고해야 할 핵심 요소는 **책임 범위 명확화**, **수수료 구조의 투명성**, **금지품목/관세 리스크의 고객 전가 방식**이다.

## 1. 서비스 약관 (Terms of Service) 핵심 분석

**최종 업데이트**: 2025-12-03

### 1.1 회원 관리
| 항목 | Delivered Korea 규정 | PayNShip 적용 시사점 |
|------|---------------------|---------------------|
| 가입 연령 | 만 18세 이상 | 동일 적용 |
| 계정 양도 | 불가 (패키지 포함) | 동일 적용 |
| 본인 확인 | 여권/면허증 등 요구 가능 | AI 채팅 기반이므로 본인인증 단계 별도 설계 필요 |
| 계정 해지 | 미처리 거래 없을 시 가능 | 동일 적용 |

### 1.2 DK Credits (자체 크레딧 시스템)
- **eWallet Credits**: 선불 충전, 환불 불가, 5년 유효 (60개월)
- **Rewards Credits**: 마케팅 보상, 1년 유효 (12개월)
- **쿠폰**: 1회 사용, 현금 교환 불가, 양도 불가
- **환불 순서**: Credits → Coupon(환불 불가) → 나머지 원결제수단

> **PayNShip 시사점**: Shopify 기반이므로 자체 크레딧 시스템보다 Shopify Gift Card나 할인코드 활용이 현실적

### 1.3 서비스 운영 규칙

#### 패키지 수령/보관
- 무료 보관: **45일** (이후 일일 $1/패키지)
- 최대 보관: **75일** (초과 시 폐기 가능)
- 합포장 패키지는 개별 sub-package별 보관료 누적
- 외부 박스 손상 시 이메일 통보 + 재포장 서비스 권유
- **Oversized 패키지**: 한 변 70cm 초과 또는 65kg 이상

#### 합포장/재포장
- **KeepBox Consolidation**: 원래 박스 유지하며 합침 ($2/패키지)
- **Unbox Consolidation**: 원래 박스 제거 후 합침 ($3/패키지)
- **재포장**: $3/패키지
- 처리 기간: 2~4 영업일
- **한번 합포장 완료 후 변경 불가** (로딩 에어리어 이동)

#### 배송
- Express/Priority/Standard 옵션 제공 (택배사 변경 권리 보유)
- 배달 불가 시 (주소 오류, 통관 실패 등) 택배사 정책에 따라 반송/폐기
- 반송비 고객 부담 (반송 배송비 + 관세 + 재배송비)

#### 미국 배송 관세 정책
- **Pay Duties on Delivery**: 배송비에 관세 미포함, 수령 시 직접 납부
- **Prepaid All Duties**: 사전 납부 (HS코드 기준 5% + 상호관세 15% + 택배사 수수료)
- 실제 관세와 차이 시 환불 없음

### 1.4 We Buy (구매대행) 수수료 구조
| 항목 | 금액 |
|------|------|
| Handling Fee (Light) | $1.5/주문 |
| Handling Fee (Standard) | $3/주문 |
| Handling Fee (Premium) | $5/주문 |
| Transaction Fee | 상품가+국내배송비의 **8%** |
| $200 이상 주문 | Light/Standard 핸들링 무료 |

#### 검사 수준 3단계
1. **Light**: 구매+수령+보관만, 검사 없음, 하자 면책
2. **Standard**: 시각적 검사 (품목 일치, 눈에 보이는 손상 확인), 제한 부품 제거
3. **Premium**: 영상 촬영 검사, 사전주문 혜택 검사 포함

#### 검사 제외 항목 (모든 레벨 공통)
- 명품 정품 인증
- 미개봉/밀봉 제품
- 외부 박스의 경미한 손상
- 모니터 색상 차이
- 전자기기 작동 상태
- 태그 없는 색상/사이즈 차이
- 랜덤 사은품 확인
- 20개 이상 대량 구매 검사

### 1.5 환불/취소 정책
| 구분 | 규정 |
|------|------|
| You Buy (배송대행) | 반품 지원 불가 (단순 배달지일 뿐) |
| We Buy (구매대행) | 48시간 내 고객센터 연락 필요 |
| 취소 수수료 | $10 + 국내배송비(실비) + 핸들링피 + 8% 거래수수료 |
| Global Bunjang | 결제 후 교환/반품 불가 (개인 판매자) |
| 마음 변경 취소 | 원칙적 불가 |

### 1.6 법적 조항
- **법적 분쟁**: 한국법 적용, 소송 전 40일 이상 협의 필수
- **면책**: 배송 중 분실/파손 보상 $100 한도 (보험 미가입 시)
- **관세 신고**: 고객이 정확한 가치 신고 의무, 허위 신고 시 고객 책임
- **사기 방지**: 계정 정지, 물품 보류, 구매 증빙 요구 권리
- **불가항력**: 자연재해, 전쟁, 폭동, 항공기 사고 등 면책

## 2. 개인정보처리방침 (Privacy Policy) 핵심 분석

**최종 업데이트**: 2025-09-16

| 자동 수집 | IP주소, OS, 브라우저, 쿠키, 로케일 |

### 2.2 이용 목적
- 서비스 이행 (수령, 보관, 배송, 통관)
- 계정 관리
- 프로모션/뉴스레터
- 웹사이트 분석 (제3자 트래킹 도구 사용)
- 합법적 비즈니스 이익 (트렌드 분석, 시장 연구)

### 2.3 제3자 제공
- 배송업체 (택배사)
- 통관/규제 기관 (법적 요구 시)
- 비즈니스 파트너 (선별, 프로모션 목적)
- 법적 요구 준수를 위한 제3자

### 2.4 보안
- SSL 암호화
- PCI DSS 준수
- 신용카드 정보 자체 서버 미저장 (PayPal, Wise 등 결제사 관리)
- 창고/사무실 보안 시스템 + CCTV

### 2.5 법적 준수
- **GDPR**: EU 적정성 결정 기반 (한국 인정)
- **CalOPPA**: 캘리포니아 온라인 개인정보 보호법 준수
- **COPPA**: 18세 미만 정보 수집 금지
- **데이터 유출 통지**: 72시간 내 감독기관 통보 + 개인 통지

### 2.6 사용자 권리
- 개인정보 정정/업데이트 (My Page)
- 계정 삭제/정보 제거 요청
- 뉴스레터 수신 거부

> **PayNShip 시사점**: AI 채팅 로그가 추가 수집 항목. LLM 기반 서비스 특성상 대화 데이터 처리 방침 명시 필요

## 5. PayNShip 적용 시 핵심 차이점 & 고려사항

### 5.1 서비스 모델 차이
| 항목 | Delivered Korea | PayNShip |
|------|----------------|----------|
| 서비스 유형 | 구매대행 + 배송대행 | AI 기반 구매대행 |
| 고객 접점 | 웹 + 채팅 지원 | **AI 챗봇 중심** |
| 결제 시스템 | 자체 크레딧 + PayPal/Wise | **Shopify 결제** |
| 창고 운영 | 자체 창고 (부산) | 미정 (파트너 or 자체) |
| 상품 관리 | 물리적 검사 | **LLM 기반 스크래핑 + 자동 가격 산정** |

### 5.2 PayNShip 약관에 반드시 포함해야 할 고유 항목
1. **AI 챗봇 면책**: LLM 응답의 정확성 한계, 가격 변동 리스크
2. **스크래핑 데이터 면책**: 웹사이트에서 추출한 정보의 정확성 보장 불가
3. **자동 가격 산정 면책**: 환율 변동, 배송비 추정치와 실제 차이
4. **대화 데이터 처리**: AI 학습 미사용 명시, 대화 로그 보관/삭제 정책
5. **Shopify 결제 연동**: 제3자 결제 처리 면책, Shopify 자체 약관 준수

### 5.3 벤치마킹 핵심 포인트
1. **책임 한계 명확화**: "보관만 하는 것이지 상품 품질을 보증하지 않음" 패턴 차용
2. **관세/세금 고객 부담 원칙**: 명확히 고지
3. **보관 기한 + 폐기 권리**: 45일 무료 → 75일 최대 패턴
4. **환불 불가 원칙 + 예외 처리**: 취소수수료 구조
5. **불가항력 면책**: 자연재해, 통관 지연 등
