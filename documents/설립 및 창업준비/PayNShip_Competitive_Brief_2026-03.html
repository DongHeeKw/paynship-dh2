PayNShip

Competitive & Infrastructure Brief

Date: 2026-03-06

Scope: 한국 쇼핑 프록시 시장 — 결제/인증, 법적 이슈, 결제 인프라, 경쟁사 분석

Executive Summary

1. 외국인이 한국 플랫폼에서 직접 구매하는 것은 사실상 불가능에 가깝다 — 주민등록번호 기반 인증, 한국 전화번호 필수, 연간 갱신 공인인증서 등이 결합된 진입장벽이 존재하며, 이것이 프록시 쇼핑 시장이 존재하는 근본 이유다.
2. 한국 법인으로 Stripe 계정 개설은 아직 불가능하고, PayPal은 가능하지만 해외→한국 수취만 지원한다. 현실적 대안은 PayPal 비즈니스 계정 + 해외법인(Delaware C-Corp) Stripe 조합이다.
3. 기존 경쟁사 17개+는 전부 수동(human agent) 기반이며, AI 자동화를 도입한 서비스는 아직 없다. PayNShip의 LLM 기반 자동화가 차별점이 될 수 있으나, 결제 인프라와 법적 구조 설계가 선행되어야 한다.

핵심 해석: 한국의 인증 장벽은 구조적이며, 단기간 내 해소될 가능성이 낮다. 이는 PayNShip 같은 프록시 서비스의 존재 이유가 지속된다는 의미다.

3.2 현실적 옵션 분석

Option A: PayPal 비즈니스 (가장 현실적)

+ 장점: 한국 사업자 즉시 개설 가능, 전 세계 200+ 국가 지원, 바이어 보호 프로그램 (신뢰도↑)

− 단점: 수수료 3.49%+, 한국 내 결제 불가, 분쟁 시 판매자 불리, 인출 시 환전 손실

→ 적합도: PayNShip 초기 MVP에 최적

Option B: 해외법인 + Stripe

+ 장점: 낮은 수수료(2.9%), 개발자 친화적 API, 구독/반복결제 용이

− 단점: Delaware C-Corp 설립 필요($500~2,000 + 연간 유지비), 세무 복잡

→ 적합도: Scale-up 단계에서 고려

Option C: 한국 PG사 (Eximbay/NICE)

+ 장점: 한국 규제 준수 용이, 원화 정산, 한국 고객도 결제 가능

− 단점: 해외 카드 결제 UX 열악, 글로벌 커버리지 제한

→ 적합도: 보조 결제수단으로 활용

Phase결제 인프라

4.2 비즈니스 모델 유형

Type A: 순수 Forwarding (주소 제공형)

대표: KoreaToMe
한국 주소 제공 → 고객이 직접 주문 → 수령/국제배송. 고객이 한국 사이트에서 직접 결제해야 하므로 외국인 결제 불가 문제 미해결.

Type B: 풀 프록시 (구매대행형)

대표: KoreanBuddies, Harumio, AllThatSales
고객이 URL/링크 제출 → 에이전트가 대신 구매 → 국제배송. 수동 처리로 인한 느린 응답(24~72시간), 확장성 제한.

Type C: 마켓플레이스형

대표: 일부 K-pop 굿즈 전문몰
직접 재고 확보 → 자체 사이트에서 판매. 재고 리스크, 제한된 상품 범위.

5.2 Key Risks to Monitor

  • Coupang/Naver의 글로벌 직접 판매 확대 — Coupang이 자체 글로벌 배송을 강화하면 일부 상품의 프록시 수요 감소
  • 한국 결제 규제 변화 — Stripe 한국 진출 시 경쟁 구도 변동
  • AI 경쟁사 진입 — 기존 프록시 업체가 AI 도입하거나, 글로벌 AI 커머스 플레이어가 한국 시장 진출

5.3 Competitive Moat 구축 전략

PayNShip이 수동 프록시 대비 방어할 수 있는 해자:

  • 데이터 해자: 스크래핑 데이터 축적 → 가격 예측, 배송 시간 예측 정확도 향상
  • UX 해자: 채팅 한 번으로 끝나는 구매 경험 vs 다단계 폼 제출
  • 비용 해자: AI 처리로 에이전트 인건비 제거 → 낮은 수수료 가능
  • 네트워크 효과: 상품 DB 확대 → 검색 정확도 향상 → 더 많은 유저 유입
