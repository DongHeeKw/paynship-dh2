## 1. 제도 개요

| 항목 | 내용 |
|------|------|
| **주관** | 중소벤처기업부 → 창업진흥원(KISED) |
| **지원 대상** | 사업공고일 기준 사업자등록이 없는 예비창업자 |
| **연령** | 제한 없음 (청년 만39세 이하 / 중장년 만40세 이상 구분 선발) |
| **지원 금액** | 평균 5천만원, 최대 **1억원** |
| **지원 내용** | 사업화자금(최대 8천만원) + BM 고도화 + MVP 제작 + 멘토링 |
| **제외 업종** | 단순 카페, 도소매, 유통업 등 |
| **공고 시기** | 매년 1월 말~2월 중순 (통합공고 후 세부공고) |
| **신청 채널** | K-Startup (k-startup.go.kr) |

## 2. 선정 절차 (5단계)

```
1단계: 서류 접수
   ↓
2단계: 서류평가 (PSST 사업계획서)
   ↓  ← 여기서 대부분 탈락. 가장 중요한 관문
3단계: 인큐베이팅 (주관기관 BM 고도화)
   ↓
4단계: 발표평가 (대면 PT, 창업자 역량 평가)
   ↓
5단계: 최종 선정 → 1단계 지원금(~2천만원) 집행
       → 추가 평가로 2단계 지원금(~4천만원) 차등 지급
```

## 3. PSST 사업계획서 작성 전략

### 기본 규칙

| 규칙 | 내용 |
|------|------|
| **양식** | K-Startup에서 제공하는 공식 양식 사용 (임의 변경 불가) |
| **분량** | 본문 5~8페이지 (초과 시 감점 가능) |
| **형식** | 두괄식, 도표·그래프·이미지 적극 활용 |
| **원칙** | "아이디어 소개서"가 아니라 "심사위원 체크리스트에 답하는 문서" |

### 항목별 전략적 비중

심사위원은 하루에 수십 건의 사업계획서를 본다. Problem과 Solution에서 승부가 갈린다.

| PSST 항목 | 공식 비중 | 실제 체감 비중 | 전략 |
|-----------|----------|-------------|------|
| **P (Problem)** | ~25% | **30%** | 데이터로 증명. "불편하다"가 아니라 "4조원 시장에서 80%가 구매 포기" |
| **S (Solution)** | ~30% | **35%** | 프로토타입/MVP 시연. 작동하는 데모가 가장 강력한 증거 |
| **S (Scale-up)** | ~25% | **20%** | 현실적 숫자. 과대 전망보다 보수적 추정 + 근거 |
| **T (Team)** | ~20% | **15%** | 점수 편차 적음. 간결하게 역량 증명 |

### 각 항목별 체크리스트

**P (Problem)**:
- [ ] 타겟 고객이 누구인지 명확히 정의했는가?
- [ ] 시장 규모를 공신력 있는 데이터(관세청, 통계청 등)로 뒷받침했는가?
- [ ] 기존 해결 방식의 한계를 구체적으로 지적했는가?
- [ ] "왜 지금"인지 타이밍 논거가 있는가?

**S (Solution)**:
- [ ] 솔루션이 Problem을 직접 해결하는 구조가 명확한가?
- [ ] 기술적 차별화가 도표/플로우차트로 시각화되었는가?
- [ ] 프로토타입/MVP/데모가 준비되었는가?
- [ ] 비용 구조(특히 AI 비용 절감)가 명시되었는가?

**S (Scale-up)**:
- [ ] TAM-SAM-SOM이 현실적으로 산정되었는가?
- [ ] 수익 모델이 구체적 숫자로 제시되었는가?
- [ ] GTM 전략이 단계별로 구분되어 있는가?
- [ ] 사업비 활용 계획이 구체적인가?

**T (Team)**:
- [ ] 창업자의 도메인 전문성이 드러나는가?
- [ ] 부족한 역량에 대한 보강 계획이 있는가?
- [ ] 실행력의 증거(코드베이스, 테스트, MVP)를 제시했는가?

## 4. PayNShip 특화 전략

### 강점 극대화

1. **"예비창업인데 프로덕션 시스템 보유"** — 이것이 가장 강력한 차별화. 420+ 테스트, 6개 모듈 Production 상태를 적극 어필

2. **딥테크 프레이밍**: 단순 구매대행이 아니라 "LLM + NLP + 관세 계산 + 웹 스크래핑"의 복합 기술. 2026년 정부 기조인 **딥테크 강조**와 정확히 부합

3. **시장 데이터의 압도적 구체성**: 관세청 공식 통계(4조원, 6,117만건)를 활용. 추정치가 아닌 팩트

### 약점 보완

| 약점 | 대응 |
|------|------|
| "구매대행 = 유통업 아닌가?" | AI 기술 플랫폼임을 강조. 핵심 가치는 "가격 계산 엔진 + AI 에이전트"이지 물건을 직접 유통하는 것이 아님 |
| "스크래핑 합법성" | 공개 데이터 수집, robots.txt 준수 원칙 명시. 장기적으로 공식 API 파트너십 추진 |
| "1인 창업의 한계" | 기술은 이미 자동화. 물류·CS만 채용하면 운영 가능한 구조 |
| "해외 마케팅 경험 부족" | 디지털 마케팅(Reddit, Discord)은 비용 효율적. 예창패 멘토링으로 보강 |

### 주의사항

1. **"단순 도소매/유통업" 분류 리스크**: 사업자등록 시 업종 코드를 "소프트웨어 개발" 또는 "정보기술(IT) 서비스"로 등록해야 함. "무역업" "구매대행업"으로 등록하면 제외 대상 가능성

2. **사업비 집행 주의**: 예창패 사업비는 사용처 제한이 있음
   - ✅ 시제품 제작, 마케팅, 지재권, 서버비
   - ❌ 인건비(대표자), 사무실 임대(일부 예외), 차량

3. **경쟁률**: 최근 기준 약 15~20:1. 서류 통과가 가장 큰 관문

## 5. 발표평가 대비

### 발표 구조 (10분 + Q&A 5분 기준)

| 시간 | 내용 | 비중 |
|------|------|------|
| 0~2분 | Problem + Why Now | 20% |
| 2~5분 | Solution + 기술 시연 | 30% |
| 5~7분 | Scale-up + 수익모델 | 20% |
| 7~8분 | Team + 실행력 | 10% |
| 8~10분 | 사업비 활용 + 마일스톤 | 20% |

### 시연 전략

PayNShip의 가장 강력한 무기는 **작동하는 데모**다.

시연 시나리오:
1. 채팅창에 "I want to buy BTS album" 입력
2. AI가 상품 검색 결과 표시 (~2초)
3. 상품 선택 → 실시간 견적 표시 (배송비 + 관세 breakdown)
4. "이 모든 과정이 5분 안에 완료됩니다"

→ 심사위원이 "이거 진짜 되는 거구나"라고 느끼는 순간이 합격의 핵심
